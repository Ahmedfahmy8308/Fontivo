# Fontivo Community Code of Conduct

## Purpose & Values

Fontivo is an open-source initiative dedicated to providing typography tools, font management, and creative workflows for designers, typographers, and software engineers worldwide. We are committed to fostering a welcoming, respectful, and collaborative environment across all project touchpoints—including GitHub repositories, discussion forums, issue trackers, and release channels.

## Community Standards

To ensure a productive and inclusive space for all participants, community members and contributors are expected to:

- **Demonstrate Professionalism & Empathy**: Value diverse perspectives, linguistic backgrounds, and technical skill levels.
- **Provide Constructive Feedback**: Offer thoughtful, actionable suggestions focused on enhancing technical quality, user experience, and typographic accuracy.
- **Respect Privacy & Boundaries**: Safeguard contributor privacy and avoid publishing private information or credentials without consent.
- **Focus on Collaborative Goals**: Prioritize solutions that benefit the global font and design community.

Unacceptable behaviors include harassment, derogatory comments, personal attacks, trolling, or any conduct that compromises the welcoming atmosphere of the project.

## Scope & Responsibility

These guidelines apply across all official project spaces, including code repositories, pull requests, issue threads, pull request reviews, and related public communication channels where individuals represent the Fontivo project.
